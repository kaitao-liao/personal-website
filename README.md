# Kaitao Liao — Personal Website

A single-page academic portfolio built with Quarto, custom HTML, CSS, and minimal JavaScript. It is configured for GitHub Pages at `https://kaitao-liao.github.io/personal-website/`.

## Preview locally

Install [Quarto](https://quarto.org/docs/get-started/), then run:

```powershell
quarto preview --no-browser
```

## Publish

The workflow in `.github/workflows/publish.yml` renders and deploys the site when changes reach the `main` branch. In the repository settings, choose **GitHub Actions** as the Pages source.
